# Проект "Стороннее программное обеспечение" (СПО)


## Инструкция по запуску (Windows)

1. Открыть консоль.
2. Активировать venv:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

3. Запустить Label Studio:

   ```powershell
   label-studio start
   ```

4. Дождаться открытия `http://localhost:8080`
